Try Stem Generator

The demo opens in Logic Pro when a desktop user is signed in. To open it again, launch Logic Bridge from Applications.

On the demo track, choose Audio FX → Audio Units → Logic Bridge → Stem Generator. If Logic was open during installation and the Audio Unit is missing, reopen Logic.

Use the first four bars for Cycle Audio. Generation requires a configured stem service. Suno account sign-in is available separately in the plug-in.
